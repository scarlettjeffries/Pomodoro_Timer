# Pomodoro_Timer
:star2: Study timer based on the _Pomodoro_ method.

:star2: The Pomodoro technique involves 25 minutes of work followed by 5 minute breaks, and a longer break after every 4 sessions (1 hour of work)! :computer:

:star2: Learn more about the Pomodoro method [here](https://www.todoist.com/productivity-methods/pomodoro-technique)!

:star2: _Anticipated tech stack:_ HTML / CSS / JavaScript
