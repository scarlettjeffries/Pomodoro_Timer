# Pomodoro_Timer
:star2: Studio Ghibli themed study timer based on the _Pomodoro_ method.

:star2: Live Here: [Studio Ghibli Study Timer](https://studioghibli-pomodoro.netlify.app/)

:star2: The Pomodoro technique involves 25 minutes of work followed by 5 minute breaks, and a longer break after every 4 sessions (equivalent to 1 hour of work)! :computer:

:star2: Learn more about the Pomodoro method [here](https://www.todoist.com/productivity-methods/pomodoro-technique)!

:star2: Stack: HTML / CSS / JavaScript
